## [0.1.0] - 2026-11-13

### Added

- Context Oracle — Local LLM converts hints like 'my dog + birth year' into high-probability candidates
- Multi-Format — Native support for ZIP, RAR, PDF, 7z and encrypted TAR archives
- Hybrid Attacks — Combines AI guesses, dictionaries, masks and rules in one pipeline
- Likelihood Ranking — Scores and sorts candidates before expensive testing
- Live Progress — Real-time stats, ETA and chunky brutalist terminal UI
- Pluggable Strategies — Easy-to-extend attack modules and custom generators
- Safe Testing — Dry-run mode and non-destructive validation on copies
- Session Resume — Checkpoint and restart long recovery jobs
- Strength Analyzer — Evaluates archive encryption and suggests optimal attack
